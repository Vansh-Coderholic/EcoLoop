# ♻️ EcoLoop

### A Web-Based E-Waste Recycling Management Platform

EcoLoop is a web-based platform designed to encourage responsible e-waste disposal by connecting users with recycling centers.

Users can submit their electronic waste, verify their device through an image, find nearby recycling centers, book recycling requests, and earn EcoPoints and badges for verified recycling activities.

Recycling organizations can manage recycling requests and view basic e-waste statistics.

## ✨ Main Features

- User registration and login
- E-waste submission
- Device image verification
- Recycling center locator
- Recycling booking
- Recycling status tracking
- EcoPoints
- Achievement badges
- Recycling history
- Recycler dashboard
- Basic recycling analytics
